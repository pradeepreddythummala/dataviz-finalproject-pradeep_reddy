# ⚽ FIFA World Cup Match Analysis Dashboard

## 📖 Overview

This project is an interactive Streamlit dashboard for analyzing FIFA Men's World Cup matches from 1970–2022.

## 🚀 Live Demo

**Streamlit App:**  
https://dataviz-finalproject-pradeepreddy-nlbrk2cidqtwx7whnr7m9u.streamlit.app/

## 📂 GitHub Repository

https://github.com/pradeepreddythummala/dataviz-finalproject-pradeep_reddy

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly Express
- NumPy

## 📊 Dashboard Features

- Interactive filters (Team, Tournament, Stage)
- Dataset preview
- Download filtered data
- Project summary (KPIs)
- 10 interactive visualizations

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run dashboard.py
```
