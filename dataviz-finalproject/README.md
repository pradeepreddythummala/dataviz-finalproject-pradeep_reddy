# ⚽ FIFA World Cup Match Analysis Dashboard

## 📖 Overview

This project presents an interactive dashboard for analyzing FIFA Men's World Cup matches from **1970 to 2022**. Built with **Streamlit**, the dashboard enables users to explore team performance, tournament statistics, match outcomes, and key football metrics through interactive visualizations and filters.

## 🎯 Project Objectives

- Analyze FIFA World Cup match data.
- Create interactive visualizations using Plotly.
- Build a user-friendly dashboard with Streamlit.
- Provide insights into team and tournament performance.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly Express
- NumPy

## 📂 Dataset

**FIFA Men's World Cup Match Dataset (1970–2022)**

Files used:
- `fifa_wc_mens_match_dataset_1970_2022.csv`
- `fifa_worldcup_cleaned.csv`

## 📊 Dashboard Features

### Filters
- Team
- Tournament
- Stage

### Summary Metrics
- Total Matches
- Total Teams
- Total Tournaments

### Visualizations

1. Top Teams by Win Percentage
2. Average Goals by Tournament
3. Possession vs Goals Scored
4. Goals Distribution by Stage
5. Top Teams by Average Shots on Target
6. Top Teams by Average Yellow Cards
7. Highest Scoring Stadiums
8. Corners vs Goals
9. Average Possession by Team
10. Correlation Heatmap

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/pradeepreddythummala/dataviz-finalproject-pradeep_reddy.git
```

Move into the project directory:

```bash
cd dataviz-finalproject-pradeep_reddy
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run dashboard.py
```
